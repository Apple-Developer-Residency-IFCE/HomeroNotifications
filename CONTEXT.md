# Forum Notifications

This context represents notifications generated by interactions between users in the Homero Forum. Calendar notifications do not belong to this context.

## Language

**Forum Notification**:
A record addressed to a Homero user as a consequence of an interaction in the Forum.

**Recipient**:
The Homero user to whom a forum notification is addressed.

**Actor**:
The Homero user whose action originated a forum notification.

**Target**:
The topic or comment related to a forum notification.

**Homero User ID**:
The domain identifier represented by `authorUser.id`, the authentication response's `id`, and the token's `homeroId` claim.
_Avoid_: SSO Subject, authentication subject

**SSO Subject**:
The authentication identity represented by the token's `sub` claim and `authorUser.userId`.
_Avoid_: Homero User ID

**Unread Notification**:
A forum notification that has no recorded reading time.

**Read Notification**:
A forum notification that has a recorded reading time.
